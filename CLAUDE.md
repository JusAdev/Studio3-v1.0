# CLAUDE.md — Tema Studio3 - V1.0 (Export/Produção)

Este repositório é o **espelho de produção** do tema Studio3 - V1.0. Ele existe pra
ser conectado via GitHub integration ao tema real da loja Shopify (ainda não
conectado — conectar quando o projeto estiver pronto para o primeiro deploy).

**Não editar código aqui diretamente.** A edição de verdade acontece no repositório
de desenvolvimento, na pasta irmã `../Tema Studio3 - V1.0/` (rodar `shopify theme
dev` lá). Este repo só recebe uma cópia espelhada de lá quando uma mudança está
pronta pra ir ao ar — ver a seção 1 do `CLAUDE.md` do repo de dev para o workflow de
sync completo (fetch → mirror → restaurar arquivos específicos da loja → descartar
drift do Theme Editor → `theme check` → commit → confirmar com o responsável →
push).

Este `CLAUDE.md` é intencionalmente diferente do `CLAUDE.md` do repo de dev — cada
repositório tem o seu, e eles não são sincronizados no mirror.
